# Beacon Google Bridge

A Google Apps Script web app that serves Google Calendar, Google Tasks, news feeds and NHL scores to the dashboard.

- `Code.gs`: paste this into a new Apps Script project.
- `appsscript.json`: the project manifest. It turns on the Tasks API and sets the time zone.

Step-by-step instructions are in [`../SETUP-DASHBOARD.md`](../SETUP-DASHBOARD.md), Part 1.
